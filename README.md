# 🎬 Netflix Content Analysis & Insights using Python

## 📌 Project Overview

This project analyzes a Netflix-style content dataset using Python to identify patterns and trends in content type, countries, release years, ratings, movie duration, and TV show seasons.

The project demonstrates the complete data analysis workflow, from loading and cleaning the dataset to performing exploratory data analysis and creating visualizations.

A Netflix-style dashboard was also created to present the key findings in a clear and visually appealing format.

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows
- Identify countries with the highest number of titles
- Analyze content release trends over the years
- Explore rating distributions
- Analyze movie durations and TV show seasons
- Generate meaningful insights from the dataset
- Present findings through data visualizations and a dashboard

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Statistical Analysis

## 📊 Key Findings

- Movies account for **64%** of the dataset, while TV Shows account for **36%**.
- India has the highest representation with **9 titles**.
- The United States follows with **8 titles**.
- **2021 and 2024** have the highest number of titles, with **4 titles each**.
- **13+ and 16+** are the most common ratings, with **9 titles each**.
- **68%** of the titles were released from **2020 onwards**.
- Indian content includes **5 Movies and 4 TV Shows**.
